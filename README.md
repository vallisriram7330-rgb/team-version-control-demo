\# Team Version Control Demo



\## Project Description

This project demonstrates GitHub collaboration and version control using branches, pull requests, code reviews, and merge conflicts.



\## Modules

\- Module 1: Login

\- Module 2: Registration

\- Module 3: Dashboard



\## Tools Used

\- Git

\- GitHub

\- Git Bash



\## Workflow

1\. Create feature branches.

2\. Develop individual modules.

3\. Commit and push changes.

4\. Create pull requests.

5\. Review and merge changes.

6\. Resolve merge conflicts when required.
